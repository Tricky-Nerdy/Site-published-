# The Bodies We Borrow

- [Read or edit the Markdown](The%20Bodies%20We%20Borrow.md)
- [Download the Office Print Edition PDF](The_Bodies_We_Borrow_Office_Print_Edition.pdf)
- [Import, sync, and printing guide](../../PUBLICATION-GUIDE.md)

The PDF is the original 34-page US Letter Office Print Edition. The Markdown was extracted from that PDF and contains all thirteen chapters. Page-number footers were removed, wrapped lines joined, and Markdown heading markers added. Source wording and punctuation were retained; text order was checked against the PDF extraction after whitespace normalization.

The original PDF remains the reference for print layout. Editing the Markdown does not update the PDF automatically.

These navigation and workflow notes were newly written for this publication. They are not recovered copies of an earlier helper-document package.
